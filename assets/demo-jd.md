# 示例 JD（虚构，仅用于演示 JD 拆解与匹配分回归）

岗位：Java 后端开发实习生（2027 届校招实习）
城市：杭州 / 南京

任职要求：

1. 本科及以上，计算机 / 软件工程相关专业，2027 届，每周到岗 5 天、可连续实习 6 个月以上。
2. 熟悉 Java 21 基础：集合、并发、ThreadLocal、线程池参数与拒绝策略；理解 JVM / GC 与事务失效场景。
3. 熟悉 SpringBoot / SpringMVC / Spring Security / MyBatis-Plus，理解 IoC / AOP 与自动装配原理。
4. 熟悉 MySQL 8：索引、B+ 树、最左前缀、EXPLAIN、隔离级别；理解 MVCC 与行锁；能用唯一索引做幂等。
5. 熟悉 Redis 数据结构与 Lua、Redisson 分布式锁；理解缓存一致性、穿透 / 击穿 / 雪崩治理。
6. 熟悉 RESTful 接口设计、JWT 鉴权、越权防护、字段脱敏；掌握滑动窗口限流与接口防重放。
7. 熟练 Git、Maven、Linux 与多模块构建；了解接口文档与可观测性（日志 / 指标 / 链路 / traceId）。

加分项：有高并发场景的失败现场复盘、有开源仓库、了解消息队列选型。
